# CPS Test

A simple Clicks Per Second (CPS) test made with Python and Tkinter.

## Features

- 10-second click test
- CPS calculation
- Best CPS tracking
- Simple graphical interface
- Automatic reset after each test

## Requirements

- Python 3.x
- Tkinter

## How to Run

```bash
python main.py
```

## How to Use

1. Click the "INICIAR" button.
2. Click as many times as possible for 10 seconds.
3. Your CPS will be displayed when the test ends.
4. Your best CPS of the session is saved and displayed.
5. The test automatically resets after a short delay.

## Technologies

- Python
- Tkinter
